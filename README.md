# Pukhtoon Education — IELTS LMS Design Options

Three complete website design options for the Pukhtoon Education IELTS learning platform, built from the approved Google Flow designs.

- **Design 1 — Light Classic:** design-1/
- **Design 2 — Dark High Contrast:** design-2/
- **Design 3 — Sidebar App:** design-3/

Every design includes all 8 pages: Home, Courses, Mock Tests, Login / Sign Up, Student Dashboard, Reading Test Player, Results and History, Packages. All pages are interlinked for a full click-through.

Open the GitHub Pages site and pick a design from the hub page.
